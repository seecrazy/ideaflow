# IdeaFlow(灵感集)实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按用户设计文档(DESIGN.md)实现 iPhone 灵感捕捉 App 的本地完整版:极速记录、状态机、FTS+拼音搜索、标签、附件、草稿保护、回收站。

**Architecture:** SwiftUI + 程序化 Core Data 模型(可注入 in-memory 测试)。三层搜索:NSPredicate 结构化 → 独立 SQLite FTS5 索引库(串行队列维护)→ CFStringTransform 拼音(零第三方依赖)。所有状态变更只经 `IdeaStore.transition()` 单通道并强制写审计日志;所有记录形态(打字/语音/图片/链接)收敛到单一 `capture()` 管道。

**Tech Stack:** Swift 5 模式 / SwiftUI / Core Data / SQLite3(C API, FTS5)/ Speech / AVFoundation / PhotosUI / LinkPresentation / XCTest + XCUITest。

**Spec:** `DESIGN.md`(用户原文,唯一权威)。

## 范围裁剪(优化决策)

**本阶段做(全部带测试)**:数据模型五实体、状态机+审计、批量操作、软删除回收站+30天清理、草稿保护、三层搜索+搜索历史、四 Tab UI、详情页、链接抓取(5s 超时降级)、录音+转写服务、图片压缩/缩略图、导出 MD/JSON、每日回顾通知(可选)、存储管理、Face ID 锁(可选,默认关)、种子演示模式。

**入账 DEBT.md 不做**:CloudKit 同步本体(需证书/双设备,仅落 syncState 字段)、Share Extension/Widget/Control Widget/Siri App Intents/动作按钮(需扩展 target 与授权,下阶段)、键盘预热池(过度设计)、Crashlytics(需第三方账号,以 0 崩溃测试替代)、标注/裁剪编辑器、自动标签建议。

**对原设计的优化**:
1. 拼音用 `CFStringTransform`(MandarinLatin + StripCombiningMarks),不引第三方表。
2. FTS5 放独立 `SearchIndex.sqlite`(Core Data 专属其 store schema,不混建表),串行队列 upsert,设置页可重建。
3. 程序化 `NSManagedObjectModel` 替代 .xcdatamodeld,测试用 in-memory,无 XML 耦合。
4. Swift Concurrency 只做轻量 async;列表数据用 @FetchRequest(自带分批)。

## Global Constraints

- 目录/文件名全 ASCII(历史坑);展示文案中文。
- Deployment target iOS 17.0;模拟器 `iPhone 18 Pro`(已 Booted);`CODE_SIGNING_ALLOWED=NO`。
- 本地 git main 分支,每 Task 一提交;不 push。
- 状态色板硬值:#8E8E93/#98989D、#007AFF/#0A84FF、#34C759/#30D158、#FF3B30/#FF453A、#636366/#48484A、#C7C7CC/#3A3A3C(浅/深)。
- 卡片:圆角16 内边距16 间距12;缩略图 400px/0.7;原图 2048px/0.8;音频 AAC 64k 单声道。
- 零必填:标题空时自动取正文首行(≤20字)或"未命名灵感 HH:mm"。
- 回收站默认 30 天,可配置;软删除优先。

## Review Focus(测试必须钉住的暗礁)

1. FTS 查询串含引号/连字符("won't"、"3-2")→ MATCH 语法崩溃;必须转义为安全 phrase 查询。
2. 空白/纯空格输入 → capture 拒绝,不产生垃圾卡片。
3. 混合中英文标题的拼音 initials(如"微信读书Read")→ initials 只取汉字音节首字母,英文单词保留原字母小写。
4. 回收站恢复一个标签已被删除的点子 → 不崩溃,恢复有效标签。
5. 重建索引与增量 upsert 并发 → 串行队列保证最终一致(重建后 upsert 不丢)。
